# Use CubiomesKitAdwaita in your app

Learn how to set up the CubiomesKitAdwaita framework in your app.

## Overview

This article will outline the procedure for adding CubiomesKitAdwaita to
your app.

> Important: This article is still a work in progress.

CubiomesKitAdwaita and its relevant packages are gated behind the
`Adwaita` trait, which allows for CubiomesKit to remain compatible with
existing users while providing the new functionality.

For example, to run the demo app, provide the `--traits Adwaita`
argument:

```
swift run -c debug --traits Adwaita
```
